## Admin dashboard

The dashboard shows school totals and plan information. Check the selected plan and its dates before using any count or limit.

<img src="/images/app/admin/dashboard-summary.png" alt="Administrator dashboard with active subscription, last updated time, organization totals, and remaining days." />

Use it to review:

- Total students.
- Total teachers.
- Total sections.
- Plan information.
- How much of each available resource is in use.
- Renewal status for active subscriptions.

When more than one plan is available, choose the correct plan before checking available accounts.

<Info>
  “Unlimited” means there is no fixed maximum. For fixed limits, compare used accounts with the total before creating new ones.
</Info>

## Read the page in order

1. Confirm the plan status and date range.
2. Check when the data was last updated.
3. Review Student, Teacher, and Section totals.
4. Note how long the plan remains active.
5. Compare used accounts with the limit.

<img src="/images/app/admin/usage-and-quotas.png" alt="Usage Overview cards and Quota and Limits table for licensed organization resources." />

<Warning>
  Dashboard counts provide orientation. Open the detailed list before changing a specific account, section, or assessment.
</Warning>
