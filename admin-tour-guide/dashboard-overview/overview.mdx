# Admin dashboard

The dashboard summarizes organization capacity and subscription health. Confirm the selected subscription and its date range before using any count or limit.

<img src="/images/app/admin/dashboard-summary.png" alt="Administrator dashboard with active subscription, last updated time, organization totals, and remaining days." />

Use it to review:

- Total students.
- Total teachers.
- Total sections.
- License or subscription information.
- Utilization by licensed resource.
- Renewal status for active subscriptions.

When more than one subscription is available, select the intended subscription before interpreting capacity.

<Info>
  “Unlimited” capacity is shown differently from a fixed limit. For fixed limits, compare used seats with the total before creating new accounts.
</Info>

## Read the page in order

1. Confirm subscription status and date range.
2. Check when the data was last updated.
3. Review Student, Teacher, and Section totals.
4. Note remaining subscription time.
5. Compare usage with quota limits.

<img src="/images/app/admin/usage-and-quotas.png" alt="Usage Overview cards and Quota and Limits table for licensed organization resources." />

<Warning>
  Dashboard counts provide orientation. Open the detailed list before changing a specific account, section, or assessment.
</Warning>
