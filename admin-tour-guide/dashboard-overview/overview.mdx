# Admin dashboard

The dashboard summarizes organization capacity and subscription health.

Use it to review:

- Total students.
- Total teachers.
- Total sections.
- License or subscription information.
- Utilization by licensed resource.
- Renewal status for active subscriptions.

When more than one subscription is available, select the intended subscription before interpreting capacity.

<Info>
  “Unlimited” capacity is shown differently from a fixed limit. For fixed limits, compare used seats with the total before creating new accounts.
</Info>
