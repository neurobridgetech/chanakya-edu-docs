# Overview tables

Tables show the individual records behind dashboard totals. Use search and filters to find an account, then open its management area to make changes.

Do not rely on a summary count when the task requires a specific account or assignment.

<img src="/images/app/admin/student-list-filters.png" alt="Student list search with dependent class and section filters." />

Use filters from broad to specific. Select class before section when the section control is disabled.
