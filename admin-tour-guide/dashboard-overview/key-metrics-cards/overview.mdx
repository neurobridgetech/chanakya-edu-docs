# Key metric cards

The admin dashboard provides cards for students, teachers, sections, and license information. Each card combines a current value with a shortcut to the corresponding management area.

<img src="/images/app/admin/dashboard-metrics.png" alt="Administrator dashboard cards for total Students, Teachers, Sections, and remaining subscription time." />

Use cards for orientation, then open the detailed list before making changes.

The date and subscription selector above the cards define the context. A card total can differ from a filtered list, so clear list filters before reconciling counts.
