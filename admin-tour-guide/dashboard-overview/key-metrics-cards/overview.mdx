# Key metric cards

The Admin dashboard has cards for students, teachers, sections, and plan information. Each card shows a current number and opens the related area.

<img src="/images/app/admin/dashboard-metrics.png" alt="Administrator dashboard cards for total Students, Teachers, Sections, and remaining subscription time." />

Use cards for orientation, then open the detailed list before making changes.

The date and plan selector above the cards decide what they show. A card total can differ from a filtered list, so clear the list filters before comparing numbers.
