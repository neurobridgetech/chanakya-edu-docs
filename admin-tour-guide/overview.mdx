# Admin Tour Guide

Administrators use Chanakya AI to manage users, sections, licenses, and organization-level activity from a central dashboard.

## Prerequisites

Administrators need organization-provided credentials, a modern browser, and a stable internet connection. On first login, the administrator signs in with the provided account and completes any required onboarding steps.

## Dashboard overview

The admin dashboard provides organization-level visibility into platform usage and operational health. Core metrics include students, teachers, sections, and licensing information.

Overview tables help administrators inspect user and section activity without navigating through each management area separately.

## Student management

The student management area provides a searchable list of learner accounts with relevant profile and section information.

Administrators can:

- Add a student.
- Review student information.
- Edit student details.
- Reset a student's password where available.
- Remove a student when appropriate.
- Export student information for operational use.

The creation and editing flow is designed to keep account information, academic placement, and organizational data consistent.

## Teacher management

Teacher management follows a similar workflow and gives administrators control over instructor accounts and assignments.

Administrators can:

- Add a teacher.
- Review teacher information.
- Edit teacher details.
- Reset credentials where available.
- Remove teacher accounts when required.
- Export teacher information.

Teacher records can be used together with section assignments so instructors are connected to the appropriate students and classes.

## Section management

Sections organize students and teachers into operational class groups. The section management area provides section details and administrative controls for creating and maintaining these groups.

Administrators can:

- Create a new section.
- Review section details.
- View students in a section.
- Edit section information.
- Delete a section when it is no longer needed.

Section creation typically includes the class or batch identity and the users associated with that group.

## License management

The dashboard can expose license information so administrators can monitor how many seats are available and how organizational capacity is being used.

## Recommended workflow

A typical administration workflow is:

1. Review organization metrics on the dashboard.
2. Add or update students.
3. Add or update teachers.
4. Create and maintain sections.
5. Verify users are assigned correctly.
6. Monitor platform activity and license capacity.
