# Dashboard overview

Dashboard answers two questions: **What needs attention today?** and **What should I teach next?**

## Choose a class and subject

<img src="/images/app/teacher/dashboard-controls.png" alt="Teacher Dashboard controls for section, subject, and Create test." />

1. Choose an assigned **section**.
2. Choose a **subject** available for that section.
3. Check the selected class and subject before reading any numbers.
4. Select **Create test** when you are ready to plan an assessment for it.

## Scan the teaching day

<img src="/images/app/teacher/dashboard-metrics.png" alt="Teacher Dashboard cards for total students, class average, pending homework, and pending tests." />

The summary cards show class size, class average, pending homework, and pending tests. They show only the class and subject you selected.

<img src="/images/app/teacher/upcoming-tests.png" alt="Upcoming Tests panel with an empty state and Create test action." />

Use **Upcoming Tests** to check scheduled work. An empty message means there are no upcoming tests for your selection.

## Move from signals to action

<img src="/images/app/teacher/performance-insights.png" alt="Class Performance and Performance Trend panels on the Teacher Dashboard." />

<img src="/images/app/teacher/learner-signals.png" alt="Top Performers and Need Attention panels in a processing state." />

<img src="/images/app/teacher/chapter-analysis.png" alt="Chapter Analysis with performance bands and sorting control." />

- Use **Class Performance** for the current overall level.
- Use **Performance Trend** to look for change over time, not a single-test conclusion.
- Use **Top Performers** for extension opportunities.
- Use **Need Attention** as a prompt to check the student's work.
- Use **Chapter Analysis** to choose revision priorities.

<Info>
  “Processing” means the information is not ready yet. Wait before making a decision.
</Info>
