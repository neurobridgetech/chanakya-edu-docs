# Teacher dashboard

The dashboard answers two questions: what needs attention today, and how is the selected class performing?

## Set the class context

Use the class and subject selectors near the top of the dashboard. Metrics, upcoming work, performers, and chapter analysis are scoped to that selection.

<Note>
  If a selector contains only one option, it is already fixed to your current assignment.
</Note>

## Summary cards

- **Total Students** shows the number of learners in the selected class.
- **Class Average** summarizes graded performance.
- **Pending Homeworks** counts homework awaiting completion or processing.
- **Pending Tests** counts tests that have not completed their lifecycle.

## Performance insights

The dashboard can include:

- Current class standing and performance trend.
- Top performers.
- Students who may need attention.
- Chapter-level performance bands.
- Upcoming tests and direct creation actions.

Empty states are expected before students complete graded work. They do not indicate that data has been lost.

## Recommended daily routine

1. Select the class and subject.
2. Check pending work and upcoming tests.
3. Review **Need Attention** before **Top Performers**.
4. Inspect chapter analysis for topics below the expected range.
5. Open **Tests** or **Homework** to review the underlying submissions.
6. Create follow-up work when the evidence supports it.
