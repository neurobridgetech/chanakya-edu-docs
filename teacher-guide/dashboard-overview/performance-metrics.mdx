# Interpret performance metrics

- **Class Average** summarizes available graded work for the current class context.
- **Performance Trend** indicates movement across the displayed period.
- **Top Performers** highlights strong current outcomes.
- **Need Attention** surfaces learners whose available performance is below the expected range.
- **Chapter Analysis** groups outcomes into performance bands.

<Warning>
  Do not make a high-impact learner decision from one dashboard number. Check completion, assessment difficulty, individual answers, and recent context first.
</Warning>
