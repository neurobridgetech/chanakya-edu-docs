# Class overview and analytics

Start with the selected section and subject, then read the dashboard from summary to detail.

1. Check class size and pending work.
2. Review the current average and trend.
3. Compare **Top Performers** with **Need Attention**.
4. Inspect chapter analysis for shared weak areas.
5. Open the underlying test or homework before planning an intervention.

Empty panels usually mean that no matching graded data exists for the selected context.
