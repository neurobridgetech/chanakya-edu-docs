# Learner analytics

Use analytics in this order:

1. **Overview** — identify the broad class pattern.
2. **Questions** — verify where the pattern came from.
3. **Students** — identify who needs extension or follow-up.
4. **Individual analysis** — inspect a learner’s answers and evidence.
5. **Plan and reassess** — teach, practice, and collect new evidence.

<img src="/images/diagrams/teacher-analysis-decision-loop.svg" alt="Evidence-based analysis loop for teachers." />

## Interpreting groups

- **Strong performers** suggests extension work; it is not a permanent label.
- **Needs attention** is a prioritization signal; verify missing work, question difficulty, and prior evidence.
- Use performance filters to locate a group, then open an individual only when the educational purpose requires it.

<Warning>
  Learner names, roll numbers, responses, and marks are sensitive educational data. Keep analysis inside authorized systems and avoid public screenshots.
</Warning>
