# Student analysis

Use analytics in this order:

1. **Overview** — find the main class pattern.
2. **Questions** — check where the pattern came from.
3. **Students** — find who needs extension or follow-up.
4. **Individual analysis** — check one student's answers.
5. **Plan and reassess** — teach, practise, and check new results.

<img src="/images/diagrams/teacher-analysis-decision-loop.svg" alt="Evidence-based analysis loop for teachers." />

## Interpreting groups

- **Strong performers** suggests extension work; it is not a permanent label.
- **Needs attention** is a prompt to check missing work, question difficulty, and earlier work.
- Use filters to find a group, then open an individual only when needed for teaching.

<Warning>
  Student names, roll numbers, answers, and marks are private school data. Keep analysis in approved school systems and avoid public screenshots.
</Warning>
