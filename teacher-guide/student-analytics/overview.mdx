# Student analytics

Use analytics after graded submissions are available.

1. Start with the class outcome.
2. Inspect difficult questions.
3. Identify shared misconceptions.
4. Review individual learners and submissions.
5. Decide whether to reteach, re-check, or assign practice.
6. Revisit the next result to measure improvement.
