# Analyze class performance

Open **Class analysis** from a marked test or homework. It shows a class summary, question details, and student details.

## Start with outcomes

Review the class average, score pattern, completion, and strong or weak areas. Then open questions and students to understand why.

## Question insights

Use question-level analysis to identify:

- Questions with low success rates.
- Misconceptions shared by many learners.
- Items that may need rubric or answer-key review.
- Topics suitable for reteaching or targeted practice.

## Student insights

Use student-level analysis to identify:

- Learners who need follow-up.
- Strong or improving performers.
- Missing or incomplete submissions.
- Unexpected scores that warrant answer review.

<Note>
  Class analysis supports your judgment. Always check the answers before changing a question, marking guide, or student's mark.
</Note>
