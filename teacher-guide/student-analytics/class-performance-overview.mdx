# Analyze class performance

Open **Class analysis** from a graded test or homework. The analysis view combines outcome summaries with question and student details.

## Start with outcomes

Review the class average, score distribution, completion, and high-level strengths or weak areas. Then move to the question and student views to explain the aggregate result.

## Question insights

Use question-level analysis to identify:

- Questions with low success rates.
- Misconceptions shared by many learners.
- Items that may need rubric or answer-key review.
- Topics suitable for reteaching or targeted practice.

## Student insights

Use student-level analysis to identify:

- Learners who need follow-up.
- Strong or improving performers.
- Missing or incomplete submissions.
- Unexpected scores that warrant answer review.

<Note>
  Aggregate analytics support teacher judgment. Always inspect the underlying answers before changing a question, rubric, or learner mark.
</Note>
