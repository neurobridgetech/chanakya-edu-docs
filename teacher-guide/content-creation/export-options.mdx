# Export assessment content

Depending on the assessment state and enabled features, you may be able to export a question paper, answer key, or practice material.

## Before sharing an export

- Open the file and verify formatting.
- Confirm the version matches the current online paper.
- Keep answer keys separate from student copies.
- Remove learner data unless it is required.
- Store files according to your organization's policy.

<Note>
  An export is a snapshot. Later online edits do not automatically update a previously downloaded file.
</Note>
