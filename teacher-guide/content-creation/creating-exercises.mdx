# Create a test

Open **Tests**, then select **New Test**.

<Tabs>
  <Tab title="Create Test">
    <Steps>
      <Step title="Choose a class">
        Select the curriculum and class. The available sections are loaded for that class.
      </Step>
      <Step title="Choose sections and a subject">
        Select one or more sections, then choose the subject. Subject options remain unavailable until a section is selected.
      </Step>
      <Step title="Set the size">
        Choose a standard question count or **CUSTOM**. Add an optional test name that students will recognize.
      </Step>
      <Step title="Choose the date and chapters">
        Set the relevant date and curriculum chapters. Additional fields can appear when **Advanced Option** is enabled.
      </Step>
      <Step title="Submit and review">
        The **Submit** button becomes available after required fields are complete. Wait for content generation, then preview the paper.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Upload Paper">
    Upload the supported paper file, provide the required class and assignment context, and start extraction. Track the record in **Tests** while processing completes.
  </Tab>
</Tabs>

## Validation behavior

The form disables dependent controls until their prerequisites are selected. For example, a subject cannot be selected before a section. A message beneath **Submit** identifies the next missing requirement.

<Tip>
  Use a short, specific test name such as “Algebra unit check” instead of a generic name. It is easier to find later in the management table.
</Tip>
