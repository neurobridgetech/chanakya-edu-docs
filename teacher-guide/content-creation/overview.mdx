# Content creation

Teachers have three practical paths:

| Need | Start from | Input |
|---|---|---|
| Build a structured test | **Tests → New Test → Create Test** | Class, section, subject, chapters, difficulty, and distribution |
| Use an existing paper | **Tests → New Test → Upload Paper** | Question-key PDF and optional answer-key PDF |
| Assign PDF homework | **Homework → New Homework** | Section, subject, duration, question-key PDF, optional answer-key PDF |

<img src="/images/app/teacher/create-test.png" alt="Create Test form with class, batch, subject, question count, name, date, and chapter fields." />

<Tip>
  Start with the audience: confirm class, section, and subject before configuring the paper. This prevents a polished assessment from being assigned to the wrong learners.
</Tip>

## Quality gate

Before release, verify:

- assessment name and type;
- section, subject, start date, and due date;
- question count, marks, and attempt rules;
- question wording, diagrams, answer options, and answer key;
- the student-facing export does not expose answers.
