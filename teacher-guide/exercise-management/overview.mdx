# Test management

The **Tests** workspace combines creation, search, filtering, lifecycle status, and row-level actions.

A typical flow is:

1. Create or upload the paper.
2. Wait for generation or extraction.
3. Preview and validate.
4. Assign the test.
5. Monitor submissions.
6. Review grading and re-checks.
7. Publish results.
8. Use class analysis for follow-up.

Use the status and disabled actions as lifecycle signals; do not force an assessment into a later stage before required processing is complete.
