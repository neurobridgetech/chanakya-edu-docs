# Manage tests

Open **Tests** to view the assessment management table.

<Note>
  The screenshot uses demonstration data. Treat the labels and controls as a guide; your records will be different.
</Note>

## Find a test

You can search by test name, subject, or section. Combine search with filters for:

- Class.
- Section.
- Subject.
- Test type.
- Status.

Choose the class before the section, and the section before the subject. This prevents invalid filter combinations.

## Understand statuses

| Status | Meaning | Recommended action |
| --- | --- | --- |
| **Processing** | An uploaded or generated paper is still being prepared. | Wait and refresh later. |
| **Extraction Failed** | The uploaded paper could not be converted into usable questions. | Review the source and upload again. |
| **Pending** | The test exists but has not completed the review or grading lifecycle. | Preview it and check student status. |
| **Approved** | Review has accepted the content or result for the next stage. | Continue the configured release workflow. |
| **Rejected** | Review found an issue. | Correct the content or grading decision. |
| **Graded** | Submitted work has been graded. | Review students and class analysis. |
| **Published** | Results are available to students. | Monitor questions and follow-up needs. |
| **Deleted** | The test is outside the active list but may be restorable by an authorized administrator. | Restore only when needed. |

## Row actions

- **Preview exercise** opens the paper.
- **View students** shows assignment and submission status by learner.
- **Class analysis** opens aggregate insights when graded data is available.
- **More actions** contains lifecycle-specific operations.

<Info>
  Disabled actions are state-dependent. For example, analysis is unavailable before completed graded submissions exist.
</Info>

## Before using More actions

The available menu depends on the record's state and your permissions. Before deleting, restoring, approving, rejecting, or publishing:

1. Confirm the assessment name and section.
2. Check its current status.
3. Review submission and grading activity.
4. Confirm what students can currently see.
5. Complete the smallest action needed.

## Common situations

<AccordionGroup>
  <Accordion title="An uploaded paper remains in Processing">
    Wait for extraction to complete before previewing or assigning it. If the status does not change after a reasonable period, note the assessment name and contact support.
  </Accordion>
  <Accordion title="Extraction Failed appears">
    Check that the uploaded file is readable, complete, correctly oriented, and in the supported format. Correct the source and upload it again.
  </Accordion>
  <Accordion title="Class analysis is disabled">
    The assessment needs completed, graded submission data before aggregate analysis becomes available.
  </Accordion>
  <Accordion title="Students cannot see a graded result">
    Grading and publication are separate. Review the result and complete the publish step when it is ready.
  </Accordion>
</AccordionGroup>
