# Test list and status

<img src="/images/app/teacher/test-list-actions.png" alt="Manage Tests heading and New Test action." />

## Find a test

<img src="/images/app/teacher/test-list-filters.png" alt="Test list search and filters for class, batch, subject, test type, and status." />

Search by assessment name, subject, or section. Use filters from broad to narrow: **Class → Batch → Subject**, then **Test Type** and **Status**.

<img src="/images/app/teacher/test-list-columns.png" alt="Test table columns for name, class, due date, submissions, status, and actions." />

## Row actions

<img src="/images/app/teacher/test-row-actions.png" alt="Test row actions for Preview, View students, Class analysis, and More." />

- **Preview** — inspect the paper and exports.
- **View students** — review submission count, attempts, marks, and learner-level actions.
- **Class analysis** — open aggregate analysis after enough graded data exists.
- **More** — open state-dependent grading, editing, and deletion actions.

<img src="/images/app/teacher/test-more-actions.png" alt="More actions menu with Start Grading, Edit Test, and Delete." />

An action can be unavailable when the test is not ready for it. For example, **Class analysis** needs marked submissions, and marking needs submitted work.

## Mobile

<img src="/images/app/teacher/mobile-test-card.png" alt="Responsive test card with dates, submissions, status, and Preview, Students, Analysis, and More actions." />

On mobile, each table row becomes a card. The actions and status meaning remain the same.

<Note>
  An administrator may need to restore a deleted test. Do not delete work to hide an incorrect result; check the result and use the correction options.
</Note>
