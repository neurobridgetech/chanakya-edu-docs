## Manage sections

Open **Sections** to filter by class and section, review roster totals, create a new section, or open row actions.

<img src="/images/app/admin/section-list-actions.png" alt="Manage Sections heading with Create New Section action." />

<img src="/images/app/admin/section-list-filters.png" alt="Section filters for class and section." />

The list shows section name, board, Student total, Teacher total, and actions.

<img src="/images/app/admin/section-list-columns.png" alt="Section table headings for name, board, roster totals, and actions." />

## Create a section

Select **Create New Section**. Choose the board first, then the class. Enter a clear section name. The selected class determines available Students and subjects.

<img src="/images/app/admin/create-section-details.png" alt="Create Section form with board, class, section name, optional Student assignment, and available subjects." />

Use your school's naming pattern. Do not create a second section when changing class membership would solve the problem.

## Verify after saving

1. Reopen the section.
2. Confirm board, class, and section name.
3. Check Student membership.
4. Check Teacher and subject relationships.
5. Ask affected users to sign out and back in.
6. Confirm expected tests and homework remain visible.

## Row actions

- **View Students** opens the roster.
- **Edit** changes the section details.
- **Delete** removes the section only after confirmation.

<Warning>
  Deleting a section can affect current access and past reports. Check active tests, homework, and class membership before continuing.
</Warning>
