# Sections and recent changes

Sections connect a board and class to the right students, teachers, subjects, tests, and homework. Activity logs help you check important changes.

<img src="/images/diagrams/admin-section-dependency-map.svg" alt="Section dependency map connecting students, teachers and subjects, tests, and homework." />

## Use sections carefully

A section change can alter what several people can see. Before editing or deleting:

- Confirm the board, class, and section name.
- Review the Student roster.
- Review Teacher and subject relationships.
- Check active tests and homework.
- Consider historical reporting.

## Use activity as evidence

Search activity by actor, role, or event detail. Compare the event timestamp and description with the current account, section, or assessment record.

Activity logs can help answer:

- Who performed an administrative action?
- What kind of record changed?
- When did it happen?
- Does the current state match the event?

<Info>
  An activity event shows that an action was recorded. Also check the current record or ask the person to sign in again.
</Info>
