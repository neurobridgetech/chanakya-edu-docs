# Sections and activity

Sections connect learners and teachers to the right academic workflows.

## Maintain a section

- Use a clear class and section name.
- Assign the intended students and teachers.
- Confirm subject or teaching context where required.
- Review membership after edits.
- Check active assessments before deleting a section.

## Create or edit safely

1. Use the organization's established class and section naming pattern.
2. Select the correct class context.
3. Add the intended teachers and students.
4. Save once.
5. Reopen the section and verify the roster.
6. Ask affected users to sign out and back in.

<Warning>
  Deleting a section can affect access to active and historical work. Prefer correcting membership when the section itself is still valid.
</Warning>

## Review activity

Use **Activity Logs** to investigate operational changes or unexpected access. Narrow the review to the relevant time and account, then compare it with the current record.

Useful investigation details include:

- The approximate time of the event.
- The affected account or section.
- The action the user expected.
- What appeared instead.
- Whether the user refreshed or signed in again.

Avoid copying passwords, full answer sheets, or unnecessary personal data into support notes.

<Info>
  A successful account update does not always refresh an already-open session. Ask the affected user to sign out and back in after role or assignment changes.
</Info>
