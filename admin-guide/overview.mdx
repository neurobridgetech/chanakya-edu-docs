## Safe administration checklist

1. Confirm the organization and subscription context.
2. Search for an existing record before creating one.
3. Check license capacity.
4. Verify the target user's unique identifier.
5. Confirm section and subject assignments.
6. Review activity after high-impact changes.

<Warning>
  Password resets, deletions, and membership changes affect another person's access. Confirm the exact account and intended outcome before saving.
</Warning>

## Responsibility boundaries

Administrators manage access and organization structure. Teachers own instructional review and result publication. Students own their active attempts and submitted work.

When a request crosses those boundaries:

- Verify the requester's identity and authority.
- Record the reason for the change when your organization requires it.
- Avoid editing academic outcomes when an access or assignment correction is sufficient.
- Use activity logs to confirm that a high-impact change completed as intended.

## Common administrative tasks

| Task | Check first | Verify afterward |
| --- | --- | --- |
| Add a student or teacher | Existing account and license capacity | Account appears once with correct details |
| Reset access | Exact identity and approved reset process | User can sign in without exposing the new password |
| Change section membership | Correct class, section, and active work | Roster and user navigation reflect the change |
| Remove an account | Policy, identity, active work, and reporting needs | Access is removed and related records remain consistent |
| Investigate a change | Time window, account, and reported symptom | Activity event matches the current record |
