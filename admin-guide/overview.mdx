# Administrator guide

Administrators maintain the organization structure and access that teachers and students depend on. Use the Admin workspace to monitor subscription capacity, manage accounts and sections, oversee assessment records, and verify important changes.

## Admin responsibility map

| Area | Administrator owns | Verify afterward |
| --- | --- | --- |
| Subscription | Capacity, utilization, renewal awareness | Correct subscription and remaining quota |
| People | Account creation, correction, reset, and removal | One correct record with intended access |
| Sections | Board, class, roster, and teaching relationships | Students, teachers, and subjects are connected |
| Assessments | Organization-level oversight and recovery controls | Status, submissions, and reporting remain consistent |
| Activity | Investigation of operational changes | Event and current record tell the same story |

## High-impact actions

Password resets, account deletion, section deletion, and permanent assessment deletion can affect another person's access or history. Before using one:

1. Confirm the exact target.
2. Check active work and reporting dependencies.
3. Use the smallest change that solves the problem.
4. Save once.
5. Reopen the record and review activity.

<Warning>
  Never place passwords, answer sheets, private contact details, or full activity-log records in public support messages or screenshots.
</Warning>

## On a phone

Select the menu button at the top to open Admin navigation. The same role features are available in a stacked drawer. For long tables or complex configuration, a larger screen is easier to review before saving.
