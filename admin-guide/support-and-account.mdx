# Support and account controls

The Admin profile menu provides **Activity Logs**, **Give Feedback**, and **Logout**.

<img src="/images/app/admin/profile-menu.png" alt="Administrator profile menu with Activity Logs, Give Feedback, and Logout." />

## Give feedback

Select **Give Feedback**, choose a rating, and describe the issue or suggestion.

<img src="/images/app/admin/feedback-form.png" alt="Feedback form with experience rating, feedback text, and submit action." />

Include:

- The page and action.
- The approximate time.
- What you expected.
- What appeared instead.
- Whether the issue persists after refresh or sign-in.

Do not include passwords, full activity logs, answer sheets, exported reports, or unrelated personal information.

## Help

Select **Help** in the main menu to open the Administrator guide. If it opens in a new tab, return to the app when you finish.

## Account security

Use a unique password and do not share an Admin session. On a shared device:

1. Do not save the password in the browser.
2. Select **Logout** when finished.
3. Close the browser.
4. Change the password if someone else may know it.

<Warning>
  Admin access can affect school accounts and records. Never share an open Admin session or sign-in details.
</Warning>
