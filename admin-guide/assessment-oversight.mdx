# Oversee tests and homework

Admin access provides organization-wide assessment visibility. Open **Tests** or **Homework** to search by title and narrow the list by class, section, subject, type, or status.

<img src="/images/app/admin/test-list-filters.png" alt="Administrator Test filters for class, section, subject, test type, and status." />

The Test list shows the assessment, class, due date, submissions, status, and available actions.

<img src="/images/app/admin/test-list-columns.png" alt="Administrator Test table headings for assessment context, submissions, status, and actions." />

## Understand the default deleted view

The Admin Test and Homework pages can open with the **Deleted** status filter selected. Change **Status** to **All Status** when you need to review active work.

An empty deleted view means no matching deleted items were found. It does not mean the organization has no homework.

<img src="/images/app/admin/homework-deleted-empty-state.png" alt="Administrator Homework page with Deleted status selected and no matching homework." />

## Recover or permanently delete

Deleted Tests can expose both **Recover** and **Permanently delete** actions.

<img src="/images/app/admin/deleted-test-actions.png" alt="Deleted Test actions for preview, analysis, permanent deletion, and recovery." />

<img src="/images/diagrams/admin-deletion-decision.svg" alt="Decision guide for recovering a deleted assessment or pausing before permanent deletion." />

Use **Recover** when the item should return. Before permanent deletion, confirm:

- The exact assessment.
- Its owner and class context.
- Submission count and grading state.
- Reporting or audit requirements.
- Explicit authority to remove it permanently.

<Warning>
  Permanent deletion can be irreversible. Do not use it as a cleanup shortcut when recovery, filtering, or a status correction would solve the problem.
</Warning>

## Create homework

When enabled, select **New Homework**, choose class, section, and subject, set the duration, and upload the required question-key PDF. An answer-key PDF is optional.

<img src="/images/app/admin/create-homework.png" alt="Upload Homework form with class, section, subject, duration, question key, and optional answer key." />

Submit once and wait for processing. Reopen the list to confirm the new status.

## Instructional ownership

Administrators provide oversight and recovery controls. Teachers remain responsible for instructional content, grading review, and result publication unless organizational policy explicitly assigns otherwise.
