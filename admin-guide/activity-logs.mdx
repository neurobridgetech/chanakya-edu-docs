# Review activity logs

Open the profile menu and select **Activity Logs**.

<img src="/images/app/admin/profile-menu.png" alt="Administrator profile menu with Activity Logs, Give Feedback, and Logout." />

Use search to find a name, email, or event detail.

<img src="/images/app/admin/activity-log-search.png" alt="Activity log search field for actor and event details." />

Each row contains the actor, role, event details, and timestamp.

<img src="/images/app/admin/activity-log-columns.png" alt="Activity log headings for actor, role, details, and timestamp." />

## Investigate an event

1. Note the approximate time and what was reported.
2. Search the affected account, section, or assessment.
3. Confirm the actor and role.
4. Read the event description.
5. Compare the timestamp with the report.
6. Open the current record and verify its state.

## Interpret carefully

- An event shows an action, not always the final result.
- Several related events can belong to one set of steps.
- A password event should not reveal the password.
- A content-processing event can be followed by another status event.
- The time shown uses the app's selected region and time zone.

<Warning>
  Activity logs can contain names, User Ids, test titles, and private details. Share only the part support needs, using a safe school channel.
</Warning>
