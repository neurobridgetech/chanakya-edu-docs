# Manage Student accounts

Open **Students** to review learner accounts. The page provides **Add Student** and **Export** actions.

<img src="/images/app/admin/student-list-actions.png" alt="Manage Students heading with Add Student and Export actions." />

## Find the correct learner

Search by name, roll number, mobile number, or username. Use the class filter first; the section filter becomes available after a class is selected.

<img src="/images/app/admin/student-list-filters.png" alt="Student search with class and section filters." />

The list separates name, roll number, board, class, mobile number, username, and actions.

<img src="/images/app/admin/student-list-columns.png" alt="Student table headings for identity, academic context, contact, username, and actions." />

Use the roll number or username with the class and section. Names alone are not enough.

## Add a Student

Select **Add Student**, then enter:

- Student name.
- Roll number.
- Board.
- Class.
- Optional batch or section enrollment.
- Optional phone number.
- Optional email address.

<img src="/images/app/admin/create-student.png" alt="Create Student form with identity, board, class, optional batch, phone, and email fields." />

Choose the board before the class. The class decides which sections you can choose. Check the whole form before you submit.

## Edit or reset access

From the actions column:

- Use **Edit** to correct details or enrollment.
- Use **Reset password** only after verifying the learner.
- Use **Delete** only after checking active submissions, results, class membership, and school policy.

After an enrollment change, ask the learner to sign out and back in. Confirm that the expected tests and homework appear.

## Export safely

An exported report can contain personal information. Store it in an approved place, share it only with allowed people, and remove unneeded copies when school policy requires it.

<Warning>
  Do not use a public screenshot of the Student table. Usernames, roll numbers, contact information, and section membership are personal data.
</Warning>
