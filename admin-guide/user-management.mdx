## Manage people and access

Open **Students** or **Teachers** to search, filter, create, export, edit, reset, or remove organization accounts.

<img src="/images/diagrams/admin-user-change-safety.svg" alt="Four-step safe account change: identify, check, change, and verify." />

## Use the smallest safe change

<Steps>
  <Step title="Search first">
    Search the name and User Id. Use class, section, or assignment filters to tell similar records apart.
  </Step>
  <Step title="Check available accounts and affected work">
    Check the active plan before adding an account. Check class membership and active work before changing or removing access.
  </Step>
  <Step title="Make one focused change">
    Create, edit, reset, or remove only the intended record. Avoid changing unrelated identity or assignment fields.
  </Step>
  <Step title="Verify">
    Reopen the list, confirm the record appears once, check the right class and subject, and review activity after an important change.
  </Step>
</Steps>

## Actions available from a list

| Action | Use it for | Check first |
| --- | --- | --- |
| Add | Create a new account | Check for a duplicate and available account space |
| Export | Download the current user report | School approval and secure storage |
| Edit | Correct details or assignments | The exact account and affected work |
| Reset password | Restore access for a verified person | Identity and a safe way to share it |
| Delete | Remove account access | Policy, active work, history, and reports |

<Warning>
  A reset password is temporary sensitive information. Do not place it in documentation, screenshots, public tickets, or group chats.
</Warning>

## Duplicate accounts

Do not delete either record straight away. Check which account contains submissions, marking history, classes, or teaching assignments. Follow your school's correction process so history is not lost.
