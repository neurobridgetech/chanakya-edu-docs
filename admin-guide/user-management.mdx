# Manage people and access

Open **Students** or **Teachers** to search, filter, create, export, edit, reset, or remove organization accounts.

<img src="/images/diagrams/admin-user-change-safety.svg" alt="Four-step safe account change: identify, check, change, and verify." />

## Use the smallest safe change

<Steps>
  <Step title="Search first">
    Search the supplied name and unique identifier. Use class, section, or assignment filters to distinguish similar records.
  </Step>
  <Step title="Check capacity and dependencies">
    Review the active subscription before adding a licensed account. Check existing section membership and active work before changing or removing access.
  </Step>
  <Step title="Make one focused change">
    Create, edit, reset, or remove only the intended record. Avoid changing unrelated identity or assignment fields.
  </Step>
  <Step title="Verify">
    Reopen the list, confirm the record appears once, check the intended section or teaching context, and review activity when the change is high impact.
  </Step>
</Steps>

## Actions available from a list

| Action | Use it for | Check first |
| --- | --- | --- |
| Add | Create a new organization account | Duplicate search and license capacity |
| Export | Download the current user report | Organizational approval and secure storage |
| Edit | Correct details or assignments | Exact account and active dependencies |
| Reset password | Restore verified access | Identity and approved handoff channel |
| Delete | Remove organization access | Policy, active work, history, and reporting |

<Warning>
  A reset password is temporary sensitive information. Do not place it in documentation, screenshots, public tickets, or group chats.
</Warning>

## Duplicate accounts

Do not immediately delete either record. Determine which account contains submissions, grading history, sections, or teaching assignments. Follow the organization's correction process so history is not split or lost.
