# Use resources and study tools

Resource availability depends on your organization, class, subject, and subscription. A page can be available even when no material has been assigned to your class.

## Find class resources

1. Open **Resources** when it is available.
2. Select a class.
3. Select a subject.
4. Open or download the available material.

<img src="/images/app/student/resources-class-selection.png" alt="Resource class selector with 10th and 12th class options." />

If no subjects are available, keep the selected class and ask your teacher whether resources have been assigned. Refreshing repeatedly will not create an assignment.

<img src="/images/app/student/resources-empty-state.png" alt="Resources empty state showing that no subjects are available for the selected class." />

## Extract text from an image

The image-to-text workspace can accept uploaded images or included demo images. Extracted text appears in the panel on the right.

<img src="/images/app/student/ocr-workspace.png" alt="Image-to-text workspace with image upload, demo images, and an extracted-text panel." />

Use a clear, upright image with good lighting. Review the extracted text before copying it into notes because formulas, tables, and handwriting can be interpreted incorrectly.

<Warning>
  Do not upload identity documents, passwords, private messages, or unrelated personal information.
</Warning>
