# Filter dashboard analytics

Use the subject selector to focus the dashboard on one curriculum area. Choose **All subjects** to return to the combined view.

A filter can change:

- Overall progress.
- Test and score summaries.
- Upcoming work shown in context.
- Recommendations and study prompts.

## Use filters well

- Compare one subject at a time when planning revision.
- Return to **All subjects** before checking your overall workload.
- Do not compare percentages from different filters as if they used the same set of assessments.
- Open individual results when you need question-level evidence.

<Tip>
  Use the subject view to choose what to study, then use the combined view to plan when to do it.
</Tip>
