# Use performance insights

Insights can summarize changes over time, strong and weak topics, question-type patterns, consistency, and completion.

## Interpret carefully

- A trend is more reliable when it includes several comparable assessments.
- A weak topic means it deserves attention, not that you cannot learn it.
- A high score can still hide a repeated mistake.
- Compare results taken under similar conditions.
- Use question feedback to explain the chart.

## Make an action plan

Choose one weak concept, review the relevant class material, complete targeted practice, and check the next result for improvement.
