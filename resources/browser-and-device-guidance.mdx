## Choose a browser and device

Chanakya AI runs in a web browser. Use a current version of Chrome, Edge, Safari, or Firefox.

## Choose the right device

| Task | Recommended device |
| --- | --- |
| Check the dashboard or result | Phone, tablet, or computer |
| Complete short questions | Phone, tablet, or computer |
| Upload photographed Homework | Phone or tablet |
| Review a long paper or detailed analysis | Tablet or computer |
| Create or edit a Test | Computer |
| Grade, compare answers, or use class analysis | Computer |
| Manage accounts, sections, or exports | Computer |

Mobile layouts place table rows into cards and move navigation into a menu or bottom bar. The same action can appear in a different position.

## Before an assessment or upload

- Use a stable internet connection.
- Charge the device or connect it to power.
- Close unnecessary apps and browser tabs.
- Save important files to the device when they are stored in a cloud app.
- Allow enough time to review the final upload before the deadline.

## If the page does not display correctly

1. Refresh the page once.
2. Confirm that browser zoom is not hiding a control.
3. Close and reopen the tab.
4. Sign out and sign in again when access or assignments recently changed.
5. Try another current browser.
6. Use a larger screen for wide tables or detailed editing.

Do not open repeated tabs for the same active assessment. Continue in the tab that contains the latest saved work.

## Shared devices

- Do not let the browser save a school password on a public device.
- Sign out when finished.
- Close downloaded answer sheets and reports.
- Remove local copies when school policy requires it.
- Check that the next person cannot return to your account with the browser's Back button.

## Accessibility

Use browser zoom when text is difficult to read. Keyboard navigation and screen-reader behavior can vary by browser, so use a current browser and report the page, control, and browser when an accessibility problem blocks a task.

<Tip>
  If a device problem affects a deadline or active assessment, tell the responsible Teacher or Administrator as soon as possible.
</Tip>
