## Quick-reference handouts

Share these guides by email, messaging apps, a learning platform, or print. Each one has short steps and a link to the full guide.

- **PNG** is best for phones, email, and printing. Each file is 2400 × 3200 pixels.
- **SVG** stays clear at any size and can be edited in design software.

<Note>
  These handouts do not contain usernames, passwords, student records, or school-specific information.
</Note>
