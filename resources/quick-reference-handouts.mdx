# Quick-reference handouts

Share these public-safe guides by email, messaging apps, a learning management system, or print. Each handout uses short instructions and links readers to the detailed online guide.

- **PNG** is best for phones, email, and printing. Each file is 2400 × 3200 pixels.
- **SVG** stays sharp at any size and can be edited in compatible design software.

<Note>
  These handouts do not contain usernames, passwords, student records, or organization-specific information.
</Note>
