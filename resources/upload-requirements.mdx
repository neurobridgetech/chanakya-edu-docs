# Prepare files for upload

Read the upload window before choosing a file. Different workflows accept different formats.

## Quick rules

- Use a single PDF when the window asks for a PDF.
- When images are allowed, use clear PNG, JPG, or JPEG files.
- Do not mix a PDF and images in the same upload.
- Do not select more than one PDF.
- Keep pages upright, complete, and in reading order.
- Open the file before uploading it to confirm that it is not blank or damaged.

## Student submissions

For a Test, the final upload can require one PDF. For Homework, the upload can allow one PDF or several images.

Before selecting **Upload and Complete**:

1. Confirm that every required page is included.
2. Check that handwriting, diagrams, and page numbers are readable.
3. Remove unrelated pages and personal information.
4. Review the preview.
5. Keep the page open until completion is confirmed.

If a Homework row offers **Re-upload answer sheet**, the new file replaces the earlier answer sheet after processing. Do not re-upload unless the new file is the intended replacement.

## Files uploaded by Teachers or Administrators

When creating a Test or Homework, add the required question paper in the shown format. Add an answer key only when it is correct and ready for staff use. Keep answer keys separate from Student-facing files, and preview extracted questions, answers, marks, and diagrams before approval.

When uploading an answer sheet for a Student, confirm the Student and assessment first. A replacement can change the evidence used for marking and analysis.

## Uploading from a phone

1. Download or save a cloud file to the device.
2. Open it from the device file manager.
3. Return to Chanakya AI and select the saved copy.
4. Keep the browser open while the file is uploading.

Use a stable connection. Avoid switching apps during a final submission.

## If the file is rejected

- Confirm the accepted type shown in the window.
- Remove a selected PDF before adding images, or remove images before adding a PDF.
- Try a newly saved copy when the original file will not open.
- Reduce unnecessary pages if a large scan is slow.
- Contact your Teacher or Administrator if the deadline is near.

<Warning>
  Do not upload passwords, identity documents, private messages, unrelated Student records, or files that belong to another assessment.
</Warning>
